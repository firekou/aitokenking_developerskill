## 不可講的（出現即為不實陳述）

| 禁用語 | 為什麼 |
|---|---|
| **去中心化** | 與 AI Token 的中心化定性（Frank 2026-07-03）直接衝突，且是紅隊十條裡 七條攻擊的著力點。我方自己的引據證明第 10 條曾使用此詞，已撤回。 |
| **代幣經濟** | 同上。AI Token 不是代幣，不存在代幣經濟模型。 |
| **智能合約** | 產品不跑區塊鏈，無智能合約。出現即為事實錯誤。 |
| **已合規** | 牌照與法遵未定案前一律寫「以…為目標」。撞公司鐵律。 |

另有一組詞可以用，但**必須同時帶出限定語**，否則會超出可舉證範圍：

| 詞 | 必須同時出現 |
|---|---|
| 自動路由 | `mwf/`／`路由別名` |
| 脫敏 | `規格`／`開發中`／`尚未上線` |
| 高可用 | `99.5`／`SLA` |
| 試用額度 | `以官網`／`撤回`／`未見`／`是否有` |
| 免費額度 | `以官網`／`撤回`／`未見`／`是否有` |

第三組只出聲不擋人——**字串比對分不出「使用」與「提及」**，

| 最強 | 同上。 |
| 華為雲 | 具名第三方合作宣稱，repo 內零證據（claims.yaml P-08）。 BR-D3 未結案前，任何以我方名義做出的「支援華為雲」陳述都不得發出。 |
